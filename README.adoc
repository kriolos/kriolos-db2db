*DB2DB by ZettaIS* is an industrial-grade, high-performance database migration platform engineered from the ground up in modern Java (targeting **OpenJDK 25**, **Quarkus 4**, and **GraalVM Native Image**). It modernizes and supersedes legacy Perl-based migration utilities (such as ora2pg) with zero external script runtime dependencies, lock-free parallel streaming, and state-machine orchestration.

DB2DB automates metadata introspection, schema DDL generation, semantic procedural code transpilation (PL/SQL to PL/pgSQL), spatial geometry conversion (Oracle SDO_GEOMETRY to PostGIS), standalone executive cost assessment, parallel binary data streaming via PostgreSQL `COPY FROM STDIN` with JDK 25 Virtual Threads, and cross-database data validation audits.

== 1. Architecture Overview

DB2DB is architected as a modular Maven reactor project:

[source]
----
db2db/
├── pom.xml                 # Reactor POM (JDK 25, Quarkus 4 BOM, dependency management)
├── mvnw / mvnw.cmd         # Maven Wrapper 3.10.0
├── .mvn/wrapper/           # Wrapper configuration
├── .github/workflows/      # GitHub Actions CI & Release automation
├── ROADMAP.adoc            # Strategic multi-phase engineering roadmap
├── db2db-core/             # Migration engine, SPI extractors, DDL, i18n, transpiler, spatial, orchestrator
├── db2db-cli/              # Picocli-based standalone shaded CLI runner
└── db2db-web/              # Quarkus 4 REST, WebSocket, OpenAPI, responsive single-page web dashboard
----

== 2. Supported Database Dialects & Sources

DB2DB implements the sealed `DialectDataTypeMapper` strategy and `MetadataExtractor` SPI across enterprise DBMS sources:

* **Oracle Database** (11g, 12c, 19c, 21c, 23ai): Catalog metadata extraction (`ALL_TABLES`, `ALL_TAB_COLS`, `ALL_CONSTRAINTS`, `ALL_INDEXES`), partition schemas (RANGE, LIST, HASH), sequence parameters, and spatial `SDO_GEOMETRY`.
* **MySQL** (5.7, 8.x): `information_schema` extraction, enum/set mappings, autoincrement sequence emulation.
* **Microsoft SQL Server** (2016, 2019, 2022): `sys.tables`, `sys.columns`, identity columns, uniqueidentifiers, datetimeoffset.
* **Generic ANSI / JDBC**: Universal fallback extractor querying `java.sql.DatabaseMetaData`.

== 3. 12-Step Industrial Migration Lifecycle

DB2DB features an enterprise state machine orchestrator (`MigrationWorkflowOrchestrator`) executing an automated or operator-guided 12-step lifecycle:

[cols="1,2,3", options="header"]
|===
| Step | Phase Name | Execution Responsibility
| 1 | `PRE_FLIGHT_CHECK` | Validates network connectivity, credentials, engine versions, and destination extensions.
| 2 | `SCHEMA_ASSESSMENT` | Inspects catalog metadata, calculates migration units, invalid objects, and keyword collisions.
| 3 | `PRE_SCHEMA_SETUP` | Initializes destination schema and activates PostgreSQL extensions (`postgis`, `btree_gin`, `uuid-ossp`).
| 4 | `DDL_EXPORT` | Generates PostgreSQL-compatible DDL for tables, sequences, views, and types.
| 5 | `DDL_APPLY` | Applies structural DDL against the target PostgreSQL database.
| 6 | `PARALLEL_DATA_STREAMING` | High-throughput binary data streaming via Virtual Threads and PostgreSQL `CopyManager`.
| 7 | `POST_DATA_INDEXES` | Creates primary keys, unique, secondary, and PostGIS/GIN indexes after data is loaded.
| 8 | `FOREIGN_KEYS` | Applies deferred foreign key relationships and referential integrity constraints.
| 9 | `SEQUENCE_SYNC` | Synchronizes sequence counters with table primary key maximum values (`MAX(id)`).
| 10 | `PROCEDURAL_CODE` | Transpiles PL/SQL stored procedures, functions, packages, and triggers to native PL/pgSQL.
| 11 | `DATA_VALIDATION_AUDIT` | Cross-database row-count reconciliation and structural integrity verification.
| 12 | `FINAL_AUDIT_REPORT` | Compiles comprehensive executive audit reports in JSON and responsive standalone HTML.
|===

== 4. Multi-Language Internationalization (i18n)

DB2DB provides native multi-language support:

* **Java ResourceBundle Files**: Clean `.properties` resource bundles located in `db2db-core/src/main/resources/i18n/`:
  - `messages.properties` (Default English fallback)
  - `messages_en.properties` (English)
  - `messages_pt.properties` (Português)
* **Clean Domain Constants**: `MigrationStepId` enum constants are strictly decoupled from translation strings, resolving names and descriptions dynamically via `I18nMessages`.
* **Session Cookie Synchronization**: Language changes invoke `POST /api/v1/i18n/locale?lang={en|pt}`, synchronizing the HTTP cookie **`zettais.db2db.locale`** across client sessions, WebSocket events, and executive report generation.

== 6. Modern Java 25 Language Features

DB2DB strictly enforces modern Java language and JVM idioms:

* **Java Records**: Immutable carriers and DTOs (`Table`, `Column`, `Constraint`, `Index`, `PartitionInfo`, `SdoGeometry`, `StepExecutionRecord`, `WorkflowExecutionReport`).
* **Pattern Matching**: Type-safe AST dispatch and exception handling without manual casting.
* **Switch Expressions**: Exhaustive `switch (...) ->` expressions with zero fall-through risk.
* **Text Blocks (`"""`)**: Formatted SQL statements, DDL scripts, and report templates.
* **Virtual Threads (`Thread.ofVirtual()`)**: Unbounded parallel table streaming and asynchronous assessment using `Executors.newVirtualThreadPerTaskExecutor()`.
* **Sequenced Collections**: Direct usage of `getFirst()`, `getLast()`, and `reversed()` on ordered collections.

sdk use java 25.0.4-tem

The repository includes the Apache Maven Wrapper 3.10.0:

Result:

* Startup time: **~35 milliseconds**

== 8. CLI Usage (`db2db-cli`)

The standalone CLI offers powerful migration subcommands:

[source,bash]
----
java -jar db2db-cli/target/quarkus-app/quarkus-run.jar --help
----

=== Subcommands

==== 1. Test Database Connectivity
[source,bash]
----
java -jar db2db-cli/target/quarkus-app/quarkus-run.jar test-connection \
  --url "jdbc:oracle:thin:@//localhost:1521/ORCLPDB1" \
  --user "HR" \
  --password "secret"
----

==== 2. Analyze & Estimate Migration Effort
[source,bash]
----
# Run live schema assessment against connected database:
java -jar db2db-cli/target/quarkus-app/quarkus-run.jar analyze \
  --config db2db.conf \
  --output ./assessment-report.html \
  --format HTML

# Or generate a complete Showcase Assessment Report (no database required):
java -jar db2db-cli/target/quarkus-app/quarkus-run.jar analyze \
  --sample \
  --output ./reports/assessment-report.html \
  --format HTML
----

==== 3. Export Schema DDL
[source,bash]
----
java -jar db2db-cli/target/quarkus-app/quarkus-run.jar export-schema \
  --dialect ORACLE \
  --schema HR \
  --output ./hr-schema.sql
----

==== 4. Stream Data in Parallel (Virtual Threads)
[source,bash]
----
java -jar db2db-cli/target/quarkus-app/quarkus-run.jar export-data \
  --config db2db.conf \
  --target-url "jdbc:postgresql://localhost:5432/targetdb" \
  --target-user "postgres" \
  --target-password "secret" \
  --concurrency 16
----

==== 5. Transpile PL/SQL Code to PL/pgSQL
[source,bash]
----
java -jar db2db-cli/target/quarkus-app/quarkus-run.jar convert-sql \
  --input ./oracle_package.sql \
  --output ./pg_package.sql
----

== 10. Running with Docker & Docker Compose

DB2DB provides turnkey containerization for container runtimes and Kubernetes:

=== One-Click Migration Playground (Docker Compose)

Start the **DB2DB Web Dashboard** alongside pre-configured **PostgreSQL 17 (PostGIS)** and **MariaDB 11.4 LTS** target databases:

[source,bash]
----
docker compose up -d
----

Once started, access:
* **Web Dashboard**: `http://localhost:8080/`
* **PostgreSQL Target**: `localhost:5432` (User: `postgres`, Password: `secretpassword`, Database: `targetdb`)
* **MariaDB Target**: `localhost:3306` (User: `mariadb`, Password: `secretpassword`, Database: `targetdb`, Charset: `utf8mb4`)

To stop the containers:
[source,bash]
----
docker compose down
----

=== Building Docker Images Locally

Build the production JVM image using Eclipse Temurin 25:

[source,bash]
----
docker build -f Dockerfile.jvm -t zettais/db2db-web:latest .
----

Or build the ultra-compact GraalVM native image (after running `./mvnw clean package -Pnative -DskipTests`):

[source,bash]
----
docker build -f Dockerfile.native -t zettais/db2db-web:native .
----
