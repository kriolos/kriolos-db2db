= DB2DB by ZettaIS: Enterprise Product & Architecture Roadmap
:toc: left
:toclevels: 3
:icons: font
:source-highlighter: highlight.js

*DB2DB by ZettaIS* is an industrial-grade database migration platform engineered in modern Java (targeting **OpenJDK 25**, **Quarkus 4**, and **GraalVM Native Image**). This document outlines the strategic engineering roadmap across five progressive phases.

== Phase 1: Multi-Target Parity & End-to-End Topology (Current / Q1)

Focuses on bringing MariaDB 10.3+ to full operational parity with PostgreSQL across container topologies, data streaming, and web UI controls.

[cols="1,2,3,1", options="header"]
|===
| Milestone | Deliverables | Technical Scope | Priority
| *1.1 MariaDB Docker Service*
| Add MariaDB 11.x to `docker-compose.yml`
| Multi-container orchestration with PostgreSQL 17 + PostGIS and MariaDB 11 with UTF8mb4 collation and healthchecks.
| *High*

| *1.2 MariaDB Data Streaming Engine*
| High-Throughput MariaDB Ingestion
| High-performance streaming using batched prepared statements or `LOAD DATA LOCAL INFILE` executed across JDK 25 Virtual Threads.
| *High*

| *1.3 Web UI Target Dialect Switcher*
| Dynamic Target Selection in Web Dashboard
| Interactive dropdown in `db2db-web` allowing operator to choose between PostgreSQL and MariaDB, updating WebSocket progress.
| *High*

| *1.4 Sequence Sync for MariaDB*
| Native MariaDB sequence synchronization
| Automated `ALTER SEQUENCE ... RESTART WITH` synchronization against target primary key maximums.
| *Medium*
|===

== Phase 2: Canonical Enterprise Benchmarks & Advanced Schema Types (Q2)

Focuses on validating complex enterprise schema topologies using the canonical Oracle sample schemas with automated Testcontainers.

[cols="1,2,3,1", options="header"]
|===
| Milestone | Deliverables | Technical Scope | Priority
| *2.1 Oracle Order Entry (OE) Benchmark*
| LOBs & Object-Relational Mappings
| Automated migration of `BLOB`, `CLOB`, and nested object types to target databases.
| *High*

| *2.2 Oracle Product Media (PM) Benchmark*
| Spatial & Multi-Media Conversion
| End-to-end verification of `SDO_GEOMETRY` conversion to PostGIS geometries and MariaDB spatial types.
| *High*

| *2.3 Oracle Sales History (SH) Benchmark*
| Large-Scale Partitioning & Materialized Views
| Range, List, Hash, and composite partition DDL generation and materialized view conversion.
| *Medium*

| *2.4 Automated Testcontainers Suite*
| Ephemeral multi-DBMS integration pipeline
| Containerized CI tests spinning up Oracle Free 23ai, PostgreSQL 17, and MariaDB 11 for verified round-trip migrations.
| *Medium*
|===

== Phase 3: Semantic Procedural Transpilation 2.0 (Q3)

Transitions procedural transpilation from regex-based token matching to full Abstract Syntax Tree (AST) compilation.

[cols="1,2,3,1", options="header"]
|===
| Milestone | Deliverables | Technical Scope | Priority
| *3.1 ANTLR4 PL/SQL AST Parser*
| Syntax tree generation
| Complete grammar-based AST parsing for Oracle packages, functions, procedures, and triggers.
| *High*

| *3.2 Oracle Package Emulation*
| Package state and scoping architecture
| PostgreSQL schema-per-package emulation and session state management via temporary tables or session parameters.
| *High*

| *3.3 Bulk Collect & Forall Transpilation*
| Set-based query optimization
| Transforming PL/SQL `BULK COLLECT INTO` and `FORALL` loops into optimized SQL unnesting and array operations.
| *Medium*

| *3.4 Autonomous Transactions*
| Transaction isolation handling
| Transpiling `PRAGMA AUTONOMOUS_TRANSACTION` using `dblink` or autonomous sub-connections.
| *Medium*
|===

---

== Phase 4: Change Data Capture (CDC) & Zero-Downtime Migration (Q4)

Eliminates application downtime during mission-critical database migrations.

[cols="1,2,3,1", options="header"]
|===
| Milestone | Deliverables | Technical Scope | Priority
| *4.1 Oracle LogMiner / CDC Engine*
| Incremental transaction log capture
| Intercepting real-time INSERT, UPDATE, DELETE changes directly from Oracle redo logs without third-party agents.
| *High*

| *4.2 Continuous Delta Streaming*
| Dual-write catch-up replication
| Applying captured delta transactions to target databases post-initial load until lag converges to zero.
| *High*

| *4.3 Pre-Cutover Verification Checklist*
| Automated data validation & reconciliation
| Live row-count reconciliation, cryptographic checksum verification, and latency monitors.
| *High*

| *4.4 Zero-Downtime Switchover Automation*
| Application switchover promotion
| Read-only toggle, final sequence synchronization, and destination promotion.
| *Medium*
|===
