          DB2DB by ZettaIS • Enterprise Platform Architecture
          JDK 25 Quarkus 4 Virtual Threads v1.0.0

          DB2DB by ZettaIS is a modern, high-performance database migration platform engineered from the ground up on OpenJDK 25 and Quarkus 4. It automates catalog introspection, semantic code transpilation, zero-lock parallel data streaming, and rigorous audit validation from Oracle (19c/21c), MySQL, and SQL Server to PostgreSQL (16/17+).

          ⚡ Ultra-High Throughput Parallel Streaming
          Leverages JDK 25 Virtual Threads (Executors.newVirtualThreadPerTaskExecutor()) and PostgreSQL binary CopyManager streaming directly via piped memory buffers with zero intermediate file I/O overhead.
          🧠 Semantic PL/SQL to PL/pgSQL Transpiler
          Automated transpilation engine rewriting Oracle packages into dedicated schema namespaces, procedures, functions, autonomous transactions (dblink / pg_background), dynamic SQL (EXECUTE IMMEDIATE), and SDO_GEOMETRY to PostGIS.
          🔄 12-Step Industrial Workflow Lifecycle
          Enterprise state machine supporting unattended automatic runs or interactive step-by-step operator approvals, complete with selective phase skipping, sequence synchronizers, and cross-database row count audit reconciliation.
          📊 Assessment Scoring & Executive Audits
          Generates standalone, self-contained executive HTML and JSON migration assessment reports calculating total migration cost units, estimated human-days, schema volume rankings, and strategic remediation recommendations.
